# .NET Interview Preparation Topics

This directory organizes interview preparation material for experienced .NET developers. Start with the category closest to your current interview focus, then follow each topic's related links to build depth across the stack.

## Categories

- [C#](csharp/value-types-vs-reference-types.md) — language features, runtime behavior, memory, collections, and concurrency.
- [.NET runtime](dotnet/clr.md) — CLR, JIT, assemblies, builds, and deployment.
- [ASP.NET Core](aspnet-core/request-pipeline.md) — HTTP request processing, APIs, security, and operations.
- [Entity Framework Core](entity-framework/ef-core-overview.md) — persistence, querying, transactions, and performance.
- [SQL](sql/indexes.md) — relational modeling, query plans, indexing, and concurrency.
- [Angular](angular/angular-architecture.md) — application structure, rendering, forms, and reactive patterns.
- [AWS](aws/iam.md) — cloud infrastructure and managed services.
- [Design patterns](design-patterns/strategy.md) — reusable design approaches and their tradeoffs.
- [System design](system-design/scalability.md) — distributed systems, resilience, and scale.
- [Interview practice](interview/project-discussions.md) — behavioral, coding, debugging, and system-design preparation.

## How to use this knowledge base

Use the material to explain decisions, not just definitions. For each topic, be ready to describe the problem it addresses, its behavior and tradeoffs, how you have applied it, and how you would diagnose a failure in production. Related-topic links connect concepts that commonly appear together in interviews.
